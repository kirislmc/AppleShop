# AppleShop

## About This Project

This is my fourth Java project! I built this application independently to practice and solidify the basics I've learned so far:
- Reading user input using the `Scanner` class
- Mathematical calculations and unit conversions (converting grams to kilograms)

##  Features

- **Interactive Unit Purchase:** Enter the weight in grams for your apple purchase.
- **Automatic Price Calculation:** Automatically converts grams to kilograms and computes the exact price based on a fixed rate.
